# Lime · docs

Operational documentation for Lime (`D13`).

- `operations.md` — what Lime does and who uses it, owner and support path, access (app roles and
  approvals), data and classification (`D6`), runbooks (one per alert, `D12`), dependencies, and
  impact metrics (`D15`). **An application without this is not in production.**
- `decisions/` — decision records for anything Lime does differently from the platform defaults.
