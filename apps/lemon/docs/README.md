# Lemon · docs

Operational documentation for Lemon (`D13`).

  approvals), data and classification (`D6`), runbooks (one per alert, `D12`), dependencies, and
  impact metrics (`D15`). **An application without this is not in production.**
- `decisions/` — decision records for anything Lemon does differently from the platform defaults.
