# openspec/

Spec-driven change proposals and established specs, managed by the **OpenSpec** CLI (initialized).

- `config.yaml` — project context and authoring rules shown to AI when creating artifacts.
- `changes/`, `specs/` — proposals and established specs (created as work happens).

Drive changes through the installed OpenSpec skills / `/opsx:*` commands (propose, apply, archive,
explore, sync) rather than editing spec files by hand. See [`../AGENTS.md`](../AGENTS.md) for how
OpenSpec fits the project.
